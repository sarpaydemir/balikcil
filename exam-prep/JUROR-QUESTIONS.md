One row per open question. This index carries no wording, no options and no
numbers of any question; the content is only in the file named in each row.
Rows that name each other in the third column go to the same jurors, so each
of those rows lists every file its group needs. "Files a juror needs" is the
whole reading list: a juror is given those files and nothing else, and the
canteen book only by the line ranges named. RULES 33–35 apply to every row.
A row whose status is "withdrawn" is not to be commissioned; its file, or
the place its status names, says why. A row whose status is "ratified" is
answered; its verdict is named. A question that is not a juror's to answer
(RULES 33) is not indexed here; it is in `exam-prep/USER-QUESTIONS.md`.

## The order in which the groups sit

- **Done:** the JQ-N1 group with JQ-CANTEEN-8 is ratified; JQ-R04-GATE is
  ratified; the JQ-R04-CARRIES group (JQ-R04-CARRIES-a and -b) is ratified;
  the DATE/CONTENT group (JQ-R04-DATE-a, -b, -c and JQ-R04-CONTENT-a, -b,
  -c) is ratified. Each row names its verdict file.
- **Next:** JQ-R04-CONTENT-d, alone, from the file its row names (written
  by the eighth-fix run; not yet reviewed). Whether a review precedes its
  commission is the coordinator's; every juror file ratified so far had
  first been ruled fit by a review.
- **Three separate sets of jurors.** No juror of the JQ-R04-CARRIES group,
  of the DATE/CONTENT group or of JQ-R04-CONTENT-d sits on another of these
  three, and none is given another's file or answers. JQ-R04-CONTENT-d's
  jurors are given only the files its row names; the outcome sentences it
  needs are quoted in its file. None of them is given
  `exam-prep/USER-QUESTIONS.md` or the withdrawn sixth-fix
  JQ-R04-CONTENT-d file.
- **If the referee's verdict on JQ-R04-CONTENT-d sends the question to the
  user** (RULES 35, scope), it goes as U-1 in `exam-prep/USER-QUESTIONS.md`,
  which is marked superseded until then; what must happen to U-1 first is
  in `exam-prep/HANDED-FORWARD.md`, eighth-fix section, A-0.1.

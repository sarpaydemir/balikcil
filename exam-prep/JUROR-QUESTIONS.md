One row per open question. This index carries no wording, no options and no
numbers of any question; the content is only in the file named in each row.
Rows that name each other in the third column go to the same jurors, so each
of those rows lists every file its group needs. "Files a juror needs" is the
whole reading list: a juror is given those files and nothing else, and the
canteen book only by the line ranges named. RULES 33–35 apply to every row.
A row whose status is "withdrawn" is not to be commissioned; its file, or
the place its status names, says why. A row whose status is "ratified" is
answered; its verdict is named. A question that is not a juror's to answer
(RULES 33) is not indexed here; it is in `exam-prep/USER-QUESTIONS.md`.

## The order in which the groups sit

- **Done:** the JQ-N1 group with JQ-CANTEEN-8 is ratified.
- **Now:** the JQ-R04-CARRIES group (JQ-R04-CARRIES-a and JQ-R04-CARRIES-b),
  being answered. The DATE/CONTENT group is not commissioned until it is
  ratified.
- **After the JQ-R04-CARRIES group is ratified:** the DATE/CONTENT group
  (JQ-R04-DATE-a, -b, -c and JQ-R04-CONTENT-a, -b, -c), given the
  ratification sentence of the JQ-R04-CARRIES verdict and nothing else of it.
- **Not to jurors:** JQ-R04-CONTENT-d is withdrawn; its subject is put to
  the user as U-1 in `exam-prep/USER-QUESTIONS.md`.
- **The two R-04 groups still open have two separate sets of jurors.** No
  juror of the JQ-R04-CARRIES group sits on the DATE/CONTENT group, and
  neither is given the other's file or answers (beyond the one ratification
  sentence named above). None of them is given the JQ-R04-CONTENT-d file or
  `exam-prep/USER-QUESTIONS.md`.

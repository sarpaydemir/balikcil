## Numbering scheme

Moments are read from `data/moments/moments.csv`, whose rows are sorted by
`(symbol, start hour, kind)`. The card number is the 1-based position in that
order: `C001` .. `C306`. The moment file is fingerprinted, so the same input
always yields the same card numbers. A card file is never overwritten: if a
card with the same number already exists with different text the script stops
(RULES 30).

|---|---|
| `data/moments/moments.csv` | `1a503bc064e17b2dd217f2b2a0c1274a60f40404e681911d2c21d5459a08a761` |

## Section wall — the measured check

Every value placed in the *before* section passes `TimeGuard.before()`, which
rejects any hour that does not end at or before the start hour; every value in
the *after* section passes `TimeGuard.after()`. Per card the script also checks
that `max(before timestamp) < min(after timestamp)` and that the two timestamp
sets do not intersect. Any violation stops the script before the card is
written.

| check | value |
|---|---|
| cards written | 306 |
| timestamps guarded into the before section | 60417 |
| timestamps guarded into the after section | 9135 |
| **violations** | **0** |

The moment's kind (`large` / `calm`) and its measured 24-hour move are printed
**inside the after section only**, because both are facts about the after
window.

## Missing and empty

`MISSING` means the source could not be fetched and the reason is printed next
to it. `none` means the source was fetched and holds nothing for those hours.
`.` inside a table means the source covers the coin but published no value for
that hour. A card never implies a measurement that was not made (RULES 20).
